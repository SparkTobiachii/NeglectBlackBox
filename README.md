# Neglect Black Box reader

Public home of the Windows log reader of the Neglect CRM (hidden VRChat log reader for staff PCs). It reads the VRChat log, sends events only, and updates itself.
Builds and installers: see Releases. How it works: `client/blackbox_reader/README.md`.

The reader and `neglect/blackbox_parse.py` are copied from the (private) bot repository; do not edit them only here.
